ربط Supabase

1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor والصق ملف supabase_schema.sql المرفق ثم شغّله.
3. من إعدادات Authentication عطّل تأكيد البريد الإلكتروني لأن تسجيل الدخول هنا باسم المستخدم فقط.
4. افتح ملف index.html وابحث عن SUPABASE_URL وSUPABASE_ANON_KEY وضع رابط مشروعك ومفتاح anon/public.
5. ارفع الملف المعدل إلى GitHub Pages واختبر إنشاء الحساب.

مهم: لا تضع مفتاح service_role في HTML. لا يمكن جعل المنتدى والتصنيف حقيقيين دون تنفيذ هذه الخطوات.
